# Changelog

## v0.2.0 — Voice-first mobile + desktop foundation
- Added voice-first responsive dashboard using browser speech recognition and speech synthesis.
- Added automatic Gemini → Groq → OpenRouter fallback across configured providers.
- Added optional paired desktop companion with allow-listed media keys and selected website opening.
- Added authenticated device polling endpoints and token-based pairing.
- Added direct current-device YouTube Music search/open commands.
- Added tests for supported device command parsing.
